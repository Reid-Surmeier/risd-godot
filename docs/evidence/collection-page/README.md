# collection_page playtest evidence

The numbered screenshots are one run of `scripts/playtest.sh collection_page` on Godot 4.7.2 (X display, 1920x1080 then 1440x900, real mouse events through `Input.parse_input_event`; the harness builds the Shell with the Image Viewer desktop in the Collection Tab and nothing in the other Tabs), verified by `modules/collection_page/playtest/verify.py`, which re-hashes every screenshot, compares each window's pixels with its own screenshot file in `modules/collection_page/assets/`, the footer with the reference sheet's "number of works: 12" and the visible artworks with the sheet's cuts, and checks the logged desktop and shell states against the interface contract. `verify.json` is the verdict (57/57 pass); `report.json` is the harness log.

What they show: `01-launch` the desktop as the launch Tenant — equipment, options, Search filters, status, trade, Global Chatroom on the left, the Image Viewer top right with the first three artworks and "number of works: 12", the party window under it, the bottom bar — every window at the layout reference's place scaled to the page; `02-equipment-moved` after a title-bar drag of the equipment window (moved by the drag, now on top); `03-party-over-viewer` the party window dragged up over the viewer, drawn above it; `04-viewer-moved` after a press on the viewer's uncovered title bar and a drag: the viewer is on top again and moved, party stayed; `05-scrolled` three wheel notches down over the artworks; `06-viewer-resized` the viewer's corner dragged inward; `07-chat-clamped` the chat window dragged past the page's bottom-left corner, stopped at the edge; `08-map` the Map tab (no Tenant in this harness, white) with the desktop frozen; `09-resumed` back on Collection, identical to 07; `10-resized` the 1440x900 minimum, every window re-fitted.

`reference.png` is the owner's earlier Collection page reference (ticket #26, the RISD Museum "Collections page" window), superseded for this Tab by the owner's correction on map #23 (the Collection is prototype-81's Image Viewer desktop); it stays as the record of that attachment.

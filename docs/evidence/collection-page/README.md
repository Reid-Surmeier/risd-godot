# collection_page playtest evidence

`reference.png` is the owner's Collection page reference (ticket #26), the source of the sliced header, Info box and three object cut-outs (`modules/collection_page/PROVENANCE.md`).

The numbered screenshots are one run (bar along the bottom of the window, the page above it) of `scripts/playtest.sh collection_page` on Godot 4.7.2 (X display, 1920x1080 then 1440x900, real mouse events through `Input.parse_input_event`; the harness builds the Shell with this page in the Collection Tab and nothing in the other Tabs), verified by `modules/collection_page/playtest/verify.py`, which re-reads `collection.json` itself, re-hashes every screenshot and checks the logged page and shell states against the interface contract. `verify.json` is the verdict (40/40 pass); `report.json` is the harness log.

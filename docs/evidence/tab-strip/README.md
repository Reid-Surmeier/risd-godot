# tab_strip playtest evidence

Produced by `scripts/playtest-tab-strip.sh` (real mouse events through Godot's input pipeline on Godot 4.7.2, X display), verified by `modules/tab_strip/playtest/verify.py`, which re-hashes every screenshot and checks the logged states against the interface contract. `verify.json` is the verdict (27/27 pass); `report.json` is the harness log with timestamps; `grow.mp4` is every rendered frame of the open gesture, `close.mp4` every frame of a close (fold into a stub, then the row slides shut); `grow-frames.png` the first 24 of them; `sheet-bar.png` the toolbar band of the numbered screenshots.

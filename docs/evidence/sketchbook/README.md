# sketchbook playtest evidence (wip/sketchbook-mixbox: the Mixbox paintbox, brush and rest, tickets #48 / #49 / #63)

Produced by `scripts/playtest.sh sketchbook docs/evidence/sketchbook` on Godot 4.7.2 (X display :99, OpenGL — Mesa's OpenGL ES fallback on this WSL host, so software-rendered — window 1920x1080, then page sizes 1920x1000 and 1440x820, then 1440x900). The harness (`modules/sketchbook/playtest/harness.gd`, on `testing/harness_base.gd`) builds the Shell with the painting-tool desktop in the Sketchbook Tab and nothing in the other Tabs, drives it with real mouse events through `Input.parse_input_event`, and reaches the desktop only through `ShellInterface.tenant_state`. Verified by `modules/sketchbook/playtest/verify.py`, which re-hashes every screenshot, re-reads pixels and checks the logged states. `verify.json` is the verdict (47/47 pass); `report.json` is the harness log.

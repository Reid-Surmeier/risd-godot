# Concept references

One real, drawn icon per concept, to be handed to the model alongside the style strip.

**These are not from a game, and that is a gap worth naming.** They come from the
**Crystal Project** icon set by Everaldo Coelho (LGPL, ~2,488 icons) — a real shipped
icon set from the KDE desktop, not a game. Reid asked for a game icon of similar concept.
Crystal was chosen because it is the only large, freely licensed body of *drawn* icons
that covers these specific museum-catalogue concepts: sort order, clear filters, view
toggle, accession lookup, credit line. A game rip would be closer to the brief but the
concepts do not exist in games, and shipping ripped game art is not an option.

They serve as the **concept** authority — what a "sort order" or "clear filters" icon
looks like as an artifact someone drew — not the style authority. Style stays with Reid's
five originals.

## Verified by eye, 24 of 31 name-matches

Filename matching alone is unreliable, so every match was rendered and looked at. Seven
were rejected on sight:

| Icon | Why it was rejected |
| --- | --- |
| MED-03 Multiple views | matched a paint palette, not multiple images |
| MED-06 Point cloud | matched the Blender brand logo |
| MED-07 Conservation view | matched a paint palette; nothing in the set is an x-ray |
| MED-08 Verso | matched a reload arrow; nothing is the back of a picture |
| NAV-03 Gallery map | matched `font_bitmap`, which is nonsense |
| REC-01 Provenance | the link icon is too abstract to read as a chain of ownership |
| REC-04 Materials | matched a paint palette, not two tools crossed |

## Nineteen icons have no concept reference at all

Every department icon of a real museum object — the Egyptian canopic jar, the Gorham
teapot, the Buddha head, the dress form, the blockfront chest, the amphora — plus the
museum-specific states like *on view now*, *in this room*, *sit with it*, *verso* and
*point cloud*. No icon set contains these because no software has ever needed them.

For those, the concept reference has to be a **photograph of the actual object in the
RISD collection**, not another icon. That is a different kind of reference and a decision
for the owner.

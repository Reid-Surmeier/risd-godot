# sculpture_viewer playtest evidence (build/v0.1.0, the Sculpture Viewer desktop as the 3D Viewer Tenant)

Produced by `scripts/playtest.sh sculpture_viewer` on Godot 4.7.2 (X display :99, OpenGL — Mesa's OpenGL ES fallback on this WSL host, so software-rendered — window 1920x1080 then 1440x900). The harness (`modules/sculpture_viewer/playtest/harness.gd`, on `testing/harness_base.gd`) builds the Shell with the desktop in the 3D Viewer Tab and nothing in the other Tabs, drives it with real mouse events through `Input.parse_input_event`, and reaches the viewer only through `ShellInterface.tenant_state`. Verified by `modules/sculpture_viewer/playtest/verify.py`, which re-hashes every screenshot, re-reads pixels and checks the logged states against the Tenant contract, ticket #32 and the prototype's numbers. `verify.json` is the verdict (42/42 pass); `report.json` is the harness log with timestamps, gestures and the probe values.

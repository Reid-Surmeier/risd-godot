# Character package and recorded sound — #235

The accepted #231 rig, materials and six baked motion profiles are packaged under `modules/shell/character/`. This is a standalone validation and replacement handoff; the museum still uses visitor159.

`original-synchronized.webm`, `stone-synchronized.webm` and `adapted-synchronized.webm` preserve actual stereo Web Audio output and canvas frames, including run/dash, skid, launch and landing. An AudioWorklet records PCM; native WebCodecs timestamps canvas frames with the same AudioContext clock. An unchanged-return `performance.now()` observer records that clock at each actual cue dispatch. Each `t_audio` matches its dispatch call within one microsecond; no audio or source timestamp is shifted. Thumbnails are taken outside the capture interval. The refreshed videos use the GPU at about 29 recorded frames per second; metadata binds the actual live URL, PCK hash and renderer. Physical device output latency is separate from the measured audio-graph timing.

`media-spans.json` checks encoded packet continuity and decoded duration against that audio-clock interval. `waveform-alignment.json` compares complete source bodies and tails within a ±30 ms search. Simultaneous fitting accounts for overlapping known cues; it checks both correlation and the expected playback gains. All three profiles pass: largest cue-to-mixer delay 24.81 ms, minimum overlap-corrected correlation 0.9734, and no clipping. `browser-audio*.json` retain the cue, PCM and clock measurements.

The six-second house reference is [MaloDogfish GameCube gameplay, 388–394 seconds](https://www.youtube.com/watch?v=o7pRJ3Vhu7s&t=388s); the stone reference is [EmuRetro GameCube gameplay, 604.6–607 seconds](https://www.youtube.com/watch?v=Fd0g57lSedA&t=604s). The eight runtime WAVs are unfiltered AAC-decoded crops. They retain capture artifacts, unknown IDs and source variant differences; runtime gain makeup and lossless imports are documented in package provenance. Remaining skid, jump/landing and opening sounds are authored.

`native-package.json` binds the tested package code, canonical inputs, animation import settings, packager and exported PCK; `published.json` independently hashes the HTTPS-served bytes. `native-audio.json` exercises the real native mixer, contact suppression, one launch/landing/skid, stream overlap and remount. `appearance-metrics.json` checks actual rendered color, blink and dust against the accepted material source.

Footstep and dust dispatch follows actual sole planting. The consistent threshold suppresses most secondary toe-roll contacts: every gait requires a 50 mm lift, and planting is within 10 mm, scaled with the model. An independent 325-case regression check measures actual soles, retains swing memory across gait changes, requires each substantial swing to sound on planting, and checks one contact per foot in each steady cycle. The accepted motion and geometry are unchanged.

The standalone Web export uses native threaded stream playback and a 10 ms requested mixing buffer. Its host supplies cross-origin isolation headers. Use `python3 scripts/character_package.py` to run the package gates and rebuild, then `python3 scripts/character_package.py --serve` to serve that export. The museum integration must verify this hosting/audio combination and its own volume; the older adapter's additional +20 dB predates the House profile's +6 dB makeup.

Repository baseline passes with CI's gdtoolkit 4.5.0 after scoped inherited lint repair #237. Their logs are retained alongside the passing checks; no frozen fixture or public interface is modified to hide them. This packet does not claim production-release approval or identical sound across every original terrain/action.

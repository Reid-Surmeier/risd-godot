# Gallery wall source audit and bounded replacement — #168

The visually passing wall from the [08:00 surface trial](../evidence/surface-168-0800/README.md) still lacks original pixel provenance. Its `wall.png` (SHA-256 `1d5442054d96e092675f41929cf1245a247ec677e13f23b7eccd42f0f22f0a60`) first entered Git in [`5b58d527`](https://github.com/Reid-Surmeier/risd-godot/commit/5b58d527). The same bytes are archived as [`wall-before.png`](../../image-work/gallery-dollhouse-materials/references/wall-before.png). The commit and archived reference establish when and how it was reused; neither records a generator, provider, or original image source. Its 256×256 pixels average RGB (82.50, 90.50, 98.50), with channel standard deviations below 0.76. This is a measured description, not proof of how it was made.

There is a documented alternative source: [`wall-muse.webp`](../../modules/shell/prototype/gallery_walk4/textures/wall-muse.webp), SHA-256 `f3191776008e78ab6a3306fa164bf10b91af1a4ed43a2ac621e1cc95f8b68f36`. The [original pass record](../../image-work/gallery-dollhouse-materials/README.md) identifies OpenRouter `meta/muse-image`, one output, run `run-92ba97b16084444f177dc75f`, actual USD 0.01. Its [preflight](../../image-work/gallery-dollhouse-materials/generation-preflight.json), [prompt](../../image-work/gallery-dollhouse-materials/prompts/wall.txt), and [receipt](../../image-work/gallery-dollhouse-materials/wall-result.json) retain the ordered input and request. This trial made **no paid request**.

The [deterministic replacement recipe](../../image-work/wall-source-led-168/make.py) downsamples that exact Muse output to 256×256, scales its per-channel variation to 40%, and shifts the means to the already reviewed wall's RGB averages. It does not copy `wall.png` pixels. [`wall-source-led-168.png`](../../modules/shell/prototype/gallery_walk4/textures/wall-source-led-168.png) is the resulting prototype texture. These target averages preserve the prior visual calibration; they do not confer provenance on the earlier texture.

This branch is a bounded fallback, separate from the dirty floor worktree and from `build/v0.1.0`. The [fresh native/Web in-game comparison and independent image-only review](../evidence/wall-source-168/README.md) pass the visible wall treatment, with native artwork softness noted. The skylight/vault still fails the prior review. No claim of museum photograph redistribution rights follows from this source audit.

# Icons

`anchors/` holds the style authority and every approved Anchor.

- `anchors-all-five.png` and `anchor-1..5-*.png` — the five icons Reid drew by hand. These are the sole style authority for every Asset Pass: palette, bevel, outline weight, raster character, light direction, three-quarter projection, figure-to-tile proportion.
- `ui01-search-64.png` — the first generated Anchor. 64x64, 13 colours, approved by eye at 8x beside the five.
- `ui01-search-motion-anchor.png` — the same Anchor keyed to the `#00FF00` matte and NEAREST-upscaled x4 onto a 480 field, which is the form a Motion Pass takes as its first and last frame.

**There are no state sets here yet, and that is deliberate.** Two Motion Passes have been run; neither produced a certifiable four-state set. The frames are kept in `docs/evidence/icon-foundry/` as evidence, which is what uncertified output is. Nothing uncertified ships as an asset.

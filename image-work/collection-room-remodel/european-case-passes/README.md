# European gallery case pieces: Muse low-poly passes

Fourteen pieces in the European gallery cases are flat museum photographs in the game. On 2026-10-05 each got one Muse pass that redraws it as a low-poly front view on magenta, the same way the Rockefeller ceramics were done.

These are images only. None of them is built into the game yet: each still needs its volume geometry and a row in `european_east_additions.gd`.

Each folder holds the prompt, the padded museum photograph sent as the reference, the receipt, the result, and the result with the magenta keyed out. `pass.sh` is the script that ran them.

Provider: OpenRouter, `meta/muse-image`. 14 images, 0.14 USD.

Giambologna's River God (44.674) was sent twice and refused both times by the provider (HTTP 400), so it has no pass.
